# Amandeep Singh | Portfolio (React + Vite)

## Run locally
```
npm install
npm run dev
```

## Customize
1. Open `src/data.js` and replace every `TODO` and placeholder (links, email, stacks, "what I learned").
2. Put your resume in `public/resume.pdf`.
3. Add your Job Tracker, CineBook and WeatherNow live and GitHub links.

## Deploy (free)
1. Push this folder to a GitHub repo named `portfolio`.
2. On Vercel or Netlify, import the repo. Build command: `npm run build`, output folder: `dist`.
3. Add the live link to your GitHub profile, LinkedIn and CV.

## Optional extras
- **Project screenshots:** save an image in `public/screenshots/` (for example `job-tracker.png`) and set `screenshot: "/screenshots/job-tracker.png"` for that project in `src/data.js`. It appears at the top of the project tile.
- **Profile photo:** save it as `public/me.jpg` and set `profile.photo = "/me.jpg"` near the bottom of `src/data.js`.
